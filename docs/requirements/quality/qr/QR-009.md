# QR-009: Reject Unsafe Deployment Configuration

## Source

An operator starts a deployment.

## Stimulus

Required configuration is missing or unsafe.

## Environment

The deployment targets staging or production; development and test environments are excluded where their documented isolated configuration intentionally differs.

## Artifact

Deployment startup configuration validation.

## Response

The deployment shall refuse to start and identify the configuration setting without disclosing its value.

## Response Measure

Deployment configuration tests exercise every required setting and confirm that [Diagnostic Output](../../../terminology/glossary.md#diagnostic-output) contains no configured secret value.

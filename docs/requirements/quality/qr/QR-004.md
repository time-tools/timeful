# QR-004: Exclude Secrets From Diagnostics

## Source

The server or deployment tooling records a diagnostic.

## Stimulus

A request, failure, startup diagnostic, or health diagnostic occurs.

## Environment

Logs or [Diagnostic Output](../../../terminology/glossary.md#diagnostic-output) are emitted.

## Artifact

Server and deployment [Diagnostic Output](../../../terminology/glossary.md#diagnostic-output).

## Response

The [Diagnostic Output](../../../terminology/glossary.md#diagnostic-output) shall not include credentials, secrets, anonymous edit tokens, or URLs and headers that contain edit tokens.

## Response Measure

Automated or inspected [Diagnostic Output](../../../terminology/glossary.md#diagnostic-output) samples covering those conditions contain none of the protected values while retaining the non-sensitive context needed to diagnose the condition.

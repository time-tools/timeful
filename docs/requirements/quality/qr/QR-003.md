# QR-003: Authenticate Anonymous Edit Credentials

## Source

An anonymous event creator or respondent submits a protected mutation.

## Stimulus

The request supplies an authorization credential, omits it, substitutes another credential, uses a revoked credential, or supplies only a non-authorizing identifier.

## Environment

The event is stored.

## Artifact

Anonymous protected-mutation authorization.

## Response

The system shall accept an anonymous [Protected Event Response](../../../terminology/glossary.md#protected-event-response) mutation only when the request proves the applicable [Event Visitor Control Credential](../../../terminology/glossary.md#event-visitor-control-credential-evcc) or [Granted Event Visitor Control Credential](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc).
An event URL, respondent name, public `eventVisitorId`, or raw [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity) value shall not authorize a protected mutation.
A raw **Platform Visitor Identity** value means the unauthenticated identifier supplied as a request credential; an authenticated [Platform Visitor](../../../terminology/glossary.md#platform-visitor) session is not a raw value and authorizes [Protected Event Response](../../../terminology/glossary.md#protected-event-response) mutations through the associations [FR-062](../../functional/fr/FR-062.md) and [FR-063](../../functional/fr/FR-063.md) define.

## Response Measure

Automated tests accept the applicable credential and reject requests that omit it, substitute another credential, use a revoked [Granted Event Visitor Control Credential (Granted EVCC)](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc), or supply only a non-authorizing identifier.

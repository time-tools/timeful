# QR-010: Diagnose Failed Requests Without Exposing Data

## Source

A request fails.

## Stimulus

An operator investigates the failed request.

## Environment

The failure occurs in a staging or production deployment.

## Artifact

[Structured Log Records](../../../terminology/glossary.md#structured-log-records) and [Service Health Status](../../../terminology/glossary.md#service-health-status).

## Response

An operator shall be able to correlate the failure with [Structured Log Records](../../../terminology/glossary.md#structured-log-records) and [Service Health Status](../../../terminology/glossary.md#service-health-status) using a request correlation identifier or equivalent non-sensitive identifier.

## Response Measure

An operational exercise starts with a failed request and identifies the associated [Structured Log Records](../../../terminology/glossary.md#structured-log-records) and [Service Health Status](../../../terminology/glossary.md#service-health-status) without exposing values prohibited by [QR-004](QR-004.md).

# QR-016: Keep Observability Endpoints Private And Authenticated

## Source

A network client that is not an authorized operator or an authorized workload.

## Stimulus

The client attempts to reach the OpenObserve UI or its ingest endpoint without authorization.

## Environment

Staging or production; the deployment host exposes only the shared Caddy edge on public ports.

## Artifact

The OpenObserve listener and its ingestion API.

## Response

The OpenObserve listener shall not accept connections from public interfaces, and an ingestion request that does not present valid [Environment-Scoped Observability Credentials](../../../terminology/glossary.md#environment-scoped-observability-credential) shall be rejected rather than stored.

## Response Measure

A connection attempt from a public interface to the OpenObserve port fails.
An unauthenticated or incorrectly authenticated ingestion request is rejected, while an ingestion request with valid [Environment-Scoped Observability Credentials](../../../terminology/glossary.md#environment-scoped-observability-credential) succeeds.

# QR-015: Bound Observability Resource Use

## Source

The observability stack runs on the deployment host or a developer machine as part of a Timeful environment.

## Stimulus

OpenObserve ingests and queries logs, metrics, or traces with its default configuration.

## Environment

Development, staging, or production; a single-node OpenObserve instance; the shared deployment host has a total memory budget of 4 GB, and development runs on a developer machine.

## Artifact

The OpenObserve process and its data volume.

## Response

The observability stack shall run with explicitly configured memory and disk limits instead of default cache, query-pool, and memtable sizes, and shall remain within the storage budget of its configured retention window.

## Response Measure

Deployment configuration inspection shows explicit limits for the memory cache, the query engine memory pool, the memtable, and the disk cache.
An operational exercise that ingests and queries representative data observes the instance within its memory limit and its data volume within its disk budget, with no host-level out-of-memory termination and no sustained swapping.

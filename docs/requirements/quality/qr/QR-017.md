# QR-017: Keep Serving Requests When Observability Ingestion Fails

## Source

The observability backend or the network path to it.

## Stimulus

OpenObserve is unavailable or slow while the server handles requests.

## Environment

Staging or production; representative request load; diagnostic export enabled.

## Artifact

The server's request handling and its local diagnostic output.

## Response

The server shall continue to serve requests without exported diagnostics blocking or failing the request path, and shall retain local diagnostic output while the observability backend is unavailable.

## Response Measure

An operational exercise stops OpenObserve and drives representative requests.
The request success rate is unchanged, request latency stays within the bounds of [QR-006](QR-006.md) and [QR-007](QR-007.md), and diagnostic records are still available locally after the exercise.

# FR-081: Transfer Anonymous Guest Authority To Another Browser

An ordinary anonymous [Event Guest](../../../terminology/glossary.md#event-guest) who proves the guest's [Event Visitor Control Credential](../../../terminology/glossary.md#event-visitor-control-credential-evcc) shall be able to initiate an [Access Transfer](../../../terminology/glossary.md#access-transfer) from the event page.
The transfer link shall expire five minutes after creation.

After the target browser opens the link, displays a matching code, and the source browser approves that exact code before expiry, the system shall issue a distinct [Granted Event Visitor Control Credential](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc).
It shall authorize the target browser to manage every [Protected Event Response](../../../terminology/glossary.md#protected-event-response) owned by the source [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) for that event.
The **Granted EVCC** shall remain usable until the target browser's data is cleared or the source revokes it.
It shall not disclose the source EVCC or transfer response or [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) ownership.

Each pending transfer shall be single-use; source approval shall consume it.

This requirement excludes anonymous [Event Owner](../../../terminology/glossary.md#event-owner) authority, which is defined by [FR-083](FR-083.md).

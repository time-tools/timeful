# FR-135: Show The Pending Timed Event Occurrence Span In The Scheduling Tooltip

On the [Timed Event Scheduling Page](../../../terminology/glossary.md#timed-event-scheduling-page), while a pending [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span) exists, its tooltip shall report the pending **Timed Event Occurrence Span's** start and end times and date instead of the hovered [Time Slot](../../../terminology/glossary.md#time-slot)'s range.

The tooltip shall track the pending **Timed Event Occurrence Span** as a schedule drag changes it and after the drag is released, until it changes, is cleared, or the scheduling is saved or cancelled.

During [Availability Editing](../../../terminology/glossary.md#availability-editing), tooltips are unchanged and continue to report the hovered **Time Slot**'s range.

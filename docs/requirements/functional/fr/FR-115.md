# FR-115: Archive Events As The Event Owner

The [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to archive and unarchive the event.
The system shall authorize archiving and unarchiving through the same credentials [FR-018](FR-018.md) defines for [Event Settings](../../../terminology/glossary.md#event-settings) edits: the [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token), the associated [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity), or the owner-issued [Granted Event Visitor Control Credential (Granted EVCC)](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc).
The base [Event Visitor Control Credential (EVCC)](../../../terminology/glossary.md#event-visitor-control-credential-evcc) shall not authorize archiving or unarchiving.

An [Archived Event](../../../terminology/glossary.md#archived-event) shall remain viewable through its [Event Link](../../../terminology/glossary.md#event-link) but shall become read-only: the system shall not accept [Event Response](../../../terminology/glossary.md#event-response) or **Event Settings** mutations while the event is archived.
Unarchiving shall restore normal behavior.

For a signed-in **Event Owner**, archived events shall be grouped under an Archived section of the owner's event list.
This requirement does not specify where an anonymous **Event Owner** manages archived events.

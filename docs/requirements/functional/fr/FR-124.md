# FR-124: Place Event Archive And Delete In The Edit-Event Form Danger Zone

In the event page edit-event form, the [Event Owner](../../../terminology/glossary.md#event-owner) shall see the archive or unarchive control and the delete control under a `Danger zone` heading that is collapsed by default and expands to reveal the controls, with each control on its own row.
Selecting archive or unarchive shall apply the change, close the form, and refresh the event page to the resulting state.
Selecting delete shall present a confirmation that names the event's [Event Link](../../../terminology/glossary.md#event-link) and its [Event Responses](../../../terminology/glossary.md#event-response) as becoming inaccessible, and shall delete the event only after confirmation.

This requirement applies to the event page edit-event form.
It does not govern archive, unarchive, or delete actions in the owner's event list.

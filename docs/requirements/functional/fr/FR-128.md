# FR-128: Present An Access Transfer As Numbered Steps With Live Status

In the Manage access dialog of a source browser, the system shall present an [Access Transfer](../../../terminology/glossary.md#access-transfer) as three always-visible numbered steps in this order: creating and copying a transfer link, opening that link in the target browser, and approving the matching code the target browser displays.

The dialog shall mark the step the transfer has reached.
The matching-code input and the approval control shall be available whenever a transfer is pending, including before the source browser has observed the target browser open the link.

While a transfer is pending, the dialog shall state whether the target browser has opened the link.
Once the target browser has opened it, the dialog shall say that a code is displayed there and shall point to the approval step.
After the source browser approves, the dialog shall direct the user to finish in the target browser.

The page a target browser opens from an [Access Transfer](../../../terminology/glossary.md#access-transfer) link shall present its part of the transfer as the same numbered steps and shall keep waiting while the source browser has not approved.
When the source browser approves, that page shall reach its final step and announce that approval is complete without requiring a reload.
When the transfer is cancelled, expires, or otherwise becomes unusable while the target browser is waiting, that page shall end its wait, state that the link is no longer usable, and stop offering approval-dependent action.

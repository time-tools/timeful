# FR-018: Restrict Event Settings Editing To The Event Owner

Only the [Event Owner](../../../terminology/glossary.md#event-owner) may edit an event's [Event Settings](../../../terminology/glossary.md#event-settings).
The system shall provide the **Event Settings** editing form to that owner and shall authorize the edit through a valid [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token), the [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity) associated with that event ownership, or the [Granted Event Visitor Control Credential (Granted EVCC)](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc) that an **Event Owner** issued through [Access Transfer](../../../terminology/glossary.md#access-transfer) ([FR-083](FR-083.md)).

Other [Event Visitors](../../../terminology/glossary.md#event-visitor) shall receive [Event Settings](../../../terminology/glossary.md#event-settings) as read-only and shall not be able to save changes.
An [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token) shall authorize **Event Settings** edits only, not [Event Response](../../../terminology/glossary.md#event-response) edits.
The base [Event Visitor Control Credential (EVCC)](../../../terminology/glossary.md#event-visitor-control-credential-evcc) shall not authorize **Event Settings** edits.

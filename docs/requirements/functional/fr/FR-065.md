# FR-065: Show Event Responses For Availability Editing

Outside [Blind Availability Mode](../../../terminology/glossary.md#blind-availability-mode), when an [Event Visitor](../../../terminology/glossary.md#event-visitor) opens [Availability Editing](../../../terminology/glossary.md#availability-editing), the system shall list every [Event Response](../../../terminology/glossary.md#event-response), including [Protected Event Responses](../../../terminology/glossary.md#protected-event-response) the **Event Visitor** cannot edit.
It shall permit editing only for **Event Responses** the **Event Visitor** is authorized to edit.

## Acceptance Criteria

- Outside [Blind Availability Mode](../../../terminology/glossary.md#blind-availability-mode), before the [Event Visitor](../../../terminology/glossary.md#event-visitor) selects an [Event Response](../../../terminology/glossary.md#event-response) subset, the list orders **Event Responses** owned by the visitor's [Event Guest](../../../terminology/glossary.md#event-guest) first, then other [Open Event Responses](../../../terminology/glossary.md#open-event-response), then other [Protected Event Responses](../../../terminology/glossary.md#protected-event-response).

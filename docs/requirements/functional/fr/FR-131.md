# FR-131: Hide Calendar Autofill When It Is Disabled

When calendar autofill is disabled, the frontend shall not fill availability from calendar data on any event page.

On a [Timed Event Response Creation Page](../../../terminology/glossary.md#timed-event-response-creation-page) or a [Timed Event Response Editing Page](../../../terminology/glossary.md#timed-event-response-editing-page), the `Add availability` and `Edit availability` actions shall start [Availability Editing](../../../terminology/glossary.md#availability-editing) in manual mode without presenting the availability-source choice dialog.

During [Availability Editing](../../../terminology/glossary.md#availability-editing) on a timed event page, the system shall not render the `Calendar options` control for buffer time and working hours.

The frontend shall not start calendar-provider authorization for availability filling and shall not auto-open the group calendar-sharing invitation.

Calendar account connections, calendar event overlays, account settings, and the landing-page calendar demonstration are outside this requirement.

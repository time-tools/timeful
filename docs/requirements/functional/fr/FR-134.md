# FR-134: Place The Response Selection Control After The Response Name

Outside [Blind Availability Mode](../../../terminology/glossary.md#blind-availability-mode), while the system lists [Event Responses](../../../terminology/glossary.md#event-response) for selection, each listed row shall show the row's [Availability Status](../../../terminology/glossary.md#availability-status) for the [Slot](../../../terminology/glossary.md#slot) in context, or the response avatar when no **Slot** is in context, at the start of the row, and shall show the row's response checkbox after the response name and before the row's edit, lock, and delete actions.

The response name shall start at the same horizontal position as the [Legend Section](../../../terminology/glossary.md#legend-section) item labels.

On a phone viewport, every row shall show its response checkbox without a hover.

On a desktop viewport, an unselected row shall show its response checkbox only while hovered, and a selected row shall keep its response checkbox visible.

Selecting the response checkbox shall toggle the row's selection exactly once.

The response checkbox shall show a tick only while its row is selected, and that tick shall use the primary action color.

On a phone viewport, an unselected response checkbox shall use the primary action outline while the pointer hovers or presses the row's [Availability Status](../../../terminology/glossary.md#availability-status) control, the response name, or the checkbox itself, and shall otherwise use the neutral outline.

On a desktop viewport, an unselected response checkbox shall use the primary action outline while its row is hovered, and shall otherwise use the neutral outline.

The hovered or pressed primary action outline shall end when the pointer or touch that produced it ends, including when a tap unchecks the response checkbox.

Showing, hiding, or toggling a response checkbox shall not move the **Event Response** name or change the row height.

## Acceptance Criteria

- A selected row shows both its [Availability Status](../../../terminology/glossary.md#availability-status) indicator or avatar and a checked response checkbox.
- The response name starts at the same horizontal position as the Legend Section item labels.
- The response checkbox appears after the response name and before the row's edit, lock, and delete actions.
- On a phone viewport, an unselected row that is not hovered still shows its response checkbox.
- On a phone viewport, an unselected response checkbox uses the primary action outline without a tick while the pointer hovers or presses the [Availability Status](../../../terminology/glossary.md#availability-status) control, the response name, or the checkbox itself, and otherwise uses the neutral outline.
- On a phone viewport, ending the tap that unchecks a response checkbox returns it to the neutral outline without an additional interaction.
- On a desktop viewport, revealing the response checkbox on hover moves neither the response name nor any other row content.
- Selecting the response checkbox toggles the row's selection once and leaves the response name at the same horizontal position.

# FR-136: Reproject The Timed Event Occurrence Span Across Display Timezone Changes

Changing the [Display Timezone](../../../terminology/glossary.md#display-timezone) on the [Timed Event Scheduling Page](../../../terminology/glossary.md#timed-event-scheduling-page) shall preserve the selected start and end [Instants](../../../terminology/glossary.md#instant) of a pending [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span).
The system shall re-render the **Timed Event Occurrence Span** over the [Time Slots](../../../terminology/glossary.md#time-slot) that carry those **Instants**.

## Acceptance Criteria

- A saved [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span) follows the [Display Timezone](../../../terminology/glossary.md#display-timezone).
- A pending **Timed Event Occurrence Span** keeps its selected start and end [Instants](../../../terminology/glossary.md#instant), and its rendering and tooltip follow the **Display Timezone**.
- Confirming a pending **Timed Event Occurrence Span** after a **Display Timezone** change saves the preserved **Instants**.

# FR-126: Describe The Target Browser In The Manage Access Dialog

While the Manage access dialog in a source browser lists a [Granted Event Visitor Control Credential (Granted EVCC)](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc), the dialog shall identify the target browser that received it by browser name and operating system.

The identification shall derive from the User-Agent the target browser presented when it opened the [Access Transfer](../../../terminology/glossary.md#access-transfer) link.
When the browser name or operating system cannot be derived, the dialog shall identify the granted access without them and shall not display the User-Agent string itself.

While an [Access Transfer](../../../terminology/glossary.md#access-transfer) is pending and a target browser is displaying a matching code, the Manage access dialog shall identify that target browser by browser name and operating system.

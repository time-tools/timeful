# FR-139: Keep Desktop Event-Header Details And Controls In Independent Columns

On a desktop viewport, the event header of a [Timed Event Page](../../../terminology/glossary.md#timed-event-page) or a [Dates-Only Event Page](../../../terminology/glossary.md#dates-only-event-page) shall arrange the event details and the event controls as two independent vertical stacks that start at the same top edge.

The details stack shall contain the event title with its saved [Event Occurrence Span](../../../terminology/glossary.md#event-occurrence-span) when present, the metadata actions, and the event description.

The controls stack shall contain the availability actions above the event options, which shall appear above the schedule or delete-availability actions.

Both stacks shall use the same vertical gap between their stacked groups.

A height change in one stack shall not change the vertical position of any group in the other stack.

The mobile event header layout is excluded.

## Acceptance Criteria

- With a single-line title and no saved [Event Occurrence Span](../../../terminology/glossary.md#event-occurrence-span), the first group of each stack starts at the same top edge; when the availability actions render as a single row, the title aligns with the primary availability action, the metadata action row aligns with the event options row, and the event description starts on the same line as the schedule or delete-availability control.
- A wrapped event title, a saved [Event Occurrence Span](../../../terminology/glossary.md#event-occurrence-span), or a multiline event description moves only the groups below it in the details stack.
- A taller event control group moves only the groups below it in the controls stack.
- The availability actions render above the event options, and the event options render above the schedule or delete-availability action.
- On a phone-sized viewport, the event header keeps its single-column order.

# FR-130: Confirm Clipboard Copies At The Initiating Control

When a user activates a control that writes text to the clipboard, the system shall confirm the success at that control and automatically restore the control after two seconds.

The confirmation shall appear only after the clipboard write succeeds.

When the clipboard write fails, the system shall report the failure without removing the copyable text and without signaling success.

The system shall announce the copy outcome to assistive technology.

When the initiating control is no longer visible after activation, the system shall confirm the copy with an application-level notification.

# FR-127: Use A Six-Digit Numeric Matching Code For Access Transfers

When a target browser opens an [Access Transfer](../../../terminology/glossary.md#access-transfer) link, the system shall display the matching code as six decimal digits, including leading zeros.

Each pending target request in an [Access Transfer](../../../terminology/glossary.md#access-transfer) shall have a matching code distinct from the other pending target requests' codes.

The source browser shall accept a matching code typed with optional spaces or hyphens between digits and compare only the digits.

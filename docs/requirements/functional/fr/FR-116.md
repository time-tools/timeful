# FR-116: Delete Events As The Event Owner

The [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to delete the event.
The system shall authorize deletion through the same credentials [FR-018](FR-018.md) defines for [Event Settings](../../../terminology/glossary.md#event-settings) edits: the [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token), the associated [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity), or the owner-issued [Granted Event Visitor Control Credential (Granted EVCC)](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc).
The base [Event Visitor Control Credential (EVCC)](../../../terminology/glossary.md#event-visitor-control-credential-evcc) shall not authorize deletion.

After deletion, the event's [Event Link](../../../terminology/glossary.md#event-link) shall stop resolving for every [Event Visitor](../../../terminology/glossary.md#event-visitor), and its [Event Responses](../../../terminology/glossary.md#event-response) shall become inaccessible.
This requirement does not specify data retention, recovery, or export behavior.

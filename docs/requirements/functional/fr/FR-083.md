# FR-083: Transfer Anonymous Event Owner Authority To Another Browser

An anonymous [Event Owner](../../../terminology/glossary.md#event-owner) who proves both the owner's [Event Visitor Control Credential](../../../terminology/glossary.md#event-visitor-control-credential-evcc) and [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token) shall be able to initiate an [Access Transfer](../../../terminology/glossary.md#access-transfer).

After the target browser displays a matching code and the source browser approves that exact code within five minutes of transfer creation, the system shall issue the target browser a distinct [Granted Event Visitor Control Credential](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc) that preserves all source [Event Owner](../../../terminology/glossary.md#event-owner) powers: [Event Settings](../../../terminology/glossary.md#event-settings) editing ([FR-018](FR-018.md)), response visibility ([FR-084](FR-084.md)), event archive ([FR-115](FR-115.md)), and event deletion ([FR-116](FR-116.md)).
The **Granted EVCC** shall be revocable by the source and shall not transfer event, response, or [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) ownership.

The [Granted EVCC](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc) shall have no fixed server-side expiry and remain usable until the target browser's data is cleared or the source revokes it.
It shall not disclose the source EVCC or [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token).
Each pending transfer shall be single-use; source approval shall consume it.

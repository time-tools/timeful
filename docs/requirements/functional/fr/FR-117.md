# FR-117: Cancel A Pending Access Transfer From The Source Browser

While an [Access Transfer](../../../terminology/glossary.md#access-transfer) is pending, the source browser that initiated it shall be able to cancel the transfer.

A cancelled transfer shall become unusable: the target browser shall not be able to approve or consume it, and the system shall reject any use of its transfer link.
Cancelling a pending transfer shall not revoke a [Granted Event Visitor Control Credential (Granted EVCC)](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc) that an earlier approved transfer issued.

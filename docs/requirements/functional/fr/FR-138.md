# FR-138: Render The Event Occurrence Span In The Event Header

On the event header of a [Timed Event Page](../../../terminology/glossary.md#timed-event-page) outside [Timed Event Scheduling Page](../../../terminology/glossary.md#timed-event-scheduling-page) mode, a saved [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span) shall render below the event title for every [Event Visitor](../../../terminology/glossary.md#event-visitor).
On the event header of a [Dates-Only Event Page](../../../terminology/glossary.md#dates-only-event-page) outside [Dates-Only Event Scheduling Page](../../../terminology/glossary.md#dates-only-event-scheduling-page) mode, a saved [Dates-Only Event Occurrence Span](../../../terminology/glossary.md#dates-only-event-occurrence-span) shall render below the event title for every **Event Visitor**.
In [Timed Event Scheduling Page](../../../terminology/glossary.md#timed-event-scheduling-page) mode, the event header shall continue to render the saved [Event Occurrence Span](../../../terminology/glossary.md#event-occurrence-span), and a pending unsaved selection shall not change the rendered span.

## Acceptance Criteria

- The rendered span follows the [Display Timezone](../../../terminology/glossary.md#display-timezone) and the [Display Time Format](../../../terminology/glossary.md#display-time-format).
- A [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span) whose start and end fall on different [Civil Dates](../../../terminology/glossary.md#civil-date) renders both dates.
- A [Dates-Only Event Occurrence Span](../../../terminology/glossary.md#dates-only-event-occurrence-span) renders as a single date without a time range.
- No span text renders when no [Event Occurrence Span](../../../terminology/glossary.md#event-occurrence-span) is saved.
- In [Timed Event Scheduling Page](../../../terminology/glossary.md#timed-event-scheduling-page) mode, the event header keeps rendering the saved [Event Occurrence Span](../../../terminology/glossary.md#event-occurrence-span) instead of the pending selection.
- Saving, replacing, or clearing an [Event Occurrence Span](../../../terminology/glossary.md#event-occurrence-span) updates the rendered span without a page reload.

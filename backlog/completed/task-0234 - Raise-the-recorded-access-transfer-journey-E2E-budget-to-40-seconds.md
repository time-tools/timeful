## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The recorded access-transfer Firefox journeys in `e2e/specs/timed-event-access-transfer-firefox.spec.ts` exceed Playwright's default 30-second per-test budget under the default two-worker Firefox desktop run. The reported failures were `Source approves the exact target code for owner access` and `Source approves the exact target code for guest access`, each around 36.8 seconds, both generated by the approval loop at the spec's line 91.

The user asked to raise the time budget for these recorded transfer journeys to 40 seconds while keeping every assertion, actor context, and recording behavior unchanged.

Scope: the five recorded transfer journeys in this spec, covering both loops (the three approval modes generated at line 91 and the two reload/account-switch journeys). The lighter cancel and expired-link checks keep their current budget. No other spec or project timeout changes.

Context: `E2E_FRONTEND=bundled` remains an opt-in speedup, but the default dev-server mode must fit the new budget. `e2e/AGENTS.md` currently documents that these approval journeys can exceed their 30-second budget at two workers, so that wording must be updated with the new budget.
<!-- SECTION:DESCRIPTION:END -->

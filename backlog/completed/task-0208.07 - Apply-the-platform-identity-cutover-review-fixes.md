## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Migration split chosen over recreating the test database: a new version reaches environments that already applied 20260912120000 and stays a no-op where the rewrite already ran, while the applied migration keeps its original content.

Tombstone enforcement decided as structural rather than runtime: account resolution keys on the platform identity row that deletion removes, and re-sign-in mints a fresh uuidv7, so the unused lookup API was removed and the tests assert the tombstone row directly.

Legacy tombstone retention treated as an operator responsibility: the export script is a manual pre-migration step because migration 20260912120000 has not reached production in this change set.

Finding 4 fixed with public_id::text comparison, matching GetResponseByPublicID; route regression covers 'not-a-uuid', the retired 24-hex value, and the zero UUID.

The orphan-identity count stayed at 11 across two consecutive postgres package runs, confirming the cleanup helper removes the identity the concurrent sign-in test creates.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Remove the legacy MongoDB event runtime and its data layer so only PostgreSQL serves events.

Delete the Mongo handlers and the event-source dispatch fallback in server/routes/events.go, including the Mongo-only routes (import, duplicate, userResponded, schedule, responses, rename, decline, calendar availabilities, delete, archive), authenticatedMongoEventHandler, eventSourceHandler, and their registrations.
Delete Mongo branches in server/routes/auth.go (legacy sign-in event linking), server/routes/user.go (getEvents Mongo merge and setEventFolder Mongo branch), and server/routes/folders.go (legacy short-ID enrichment and owned-event soft delete).
Delete the server/db package (Mongo connection, collection variables, Ping, Mongo event/folder/attendee/response accessors), remove db.Init, the Mongo health-check branch, and the Mongo OG-title lookup from server/main.go, and simplify server/eventsource to PostgreSQL-only identifier handling.
Delete dead Mongo-only utilities (utils.StringToObjectID, utils/db_utils.go, utils/mail_utils.go, slackbot/messages.go) and historical one-off scripts that import server/db.
Remove frontend m_ legacy event-link handling.
Convert or delete legacy-only route tests and remove db.Init from the shared route-test helper so PostgreSQL route tests no longer require a MongoDB service.

The mongo driver remains in go.mod only because the active TASK-0199.10 tooling still needs it; TASK-0199.09.03 drops it.
<!-- SECTION:DESCRIPTION:END -->

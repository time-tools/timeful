## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-0177 flags `bson-objectid` as an odd browser dependency and asks for a drop/replace/keep decision. Two call sites remain after the PostgreSQL migration:

- `frontend/src/components/home/Dashboard.vue` sorts dashboard events by ObjectID timestamp. PostgreSQL event payloads no longer carry ObjectID timestamps, so this path may be a permanent no-op.
- `frontend/src/composables/schedule_overlap/useSignUpForm.ts` generates a client-side `_id` for new signup blocks before saving. The server now assigns PostgreSQL UUIDs, so the client identity may only need to be a stable local key.

Outcome: decide whether each path is dead, and either remove it or replace it with a maintained mechanism, then remove `bson-objectid` from `frontend/package.json` and the lockfile when no import remains.

Constraints:
- Do not change client-visible ordering or identity behavior without evidence and unit coverage.
- Keep boundary and transport types separate per ADR-001; do not add view-level coercion.
- Record the final drop/replace/keep rationale for TASK-0177.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Dropped `bson-objectid` from the frontend after both call sites were resolved by TASK-0208.04.

Decision: drop.
- Dashboard ObjectID-timestamp sorting was permanently dead: dashboard events expose the canonical short public id as `_id` (`server/routes/user.go:222`) and `GET /user/events` orders by `created_at DESC, id DESC` (`server/postgres/dashboard.go:91`), so `ObjectID.isValid` never matched and every comparison returned 0. The comparator and sort calls are removed, and `Dashboard.test.ts` asserts the rendered buckets keep the events API order.
- New signup blocks mint unique non-canonical `local-signup-block-<n>` keys from `mintLocalSignUpBlockId()` in `useSignUpForm.ts`; `useSignUpForm.test.ts` asserts the keys. A random canonical UUID would be forwarded by `canonicalSignupBlockID` and fail `ReplaceSignupBlocks`, so the local key deliberately stays non-canonical. No boundary or transport type coercion was added (ADR-001).

Delivered:
- Removed `bson-objectid` with `npm uninstall bson-objectid`; `frontend/package.json` and `frontend/package-lock.json` have no entry.
- `grep -rn bson-objectid frontend/src frontend/package.json frontend/package-lock.json` returns no references.
- Recorded the drop rationale for the parent TASK-0177 (comment #1).

Verification:
- `npm run lint`, `npm run fmt:check`, `npm run typecheck`, `npm run build`, and `npm run test:unit` (146 files, 1090 tests) pass from `frontend/`.
- No visible behavior change: Dashboard order still follows the events API, and signup block identity behavior is unchanged at the wire level.

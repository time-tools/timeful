## Implementation Plan

Repository-wide searches confirm the listed helpers have no callers outside their own definitions, and only one Go module exists (`server/go.mod`).

1. `server/services/calendar/google_calendar.go`: remove the three dead `bson` struct tags from the local `Response` struct (keep the `json` tags).
2. Delete `server/utils/response_utils.go` entirely (`PartialOmission`, `getZeroValue`, `PrivatizeResponse`, `PrivatizeEventResponse`). No callers anywhere.
3. `server/utils/utils.go`: delete `EscapeRegExp`, `Encode`, `Decode`, `Encrypt`, `Decrypt`; drop imports used only by them (`crypto/aes`, `crypto/cipher`, `crypto/rand`, `encoding/base64`, `regexp`). Keep `errors` (used by Listmonk/base-URL helpers) and all other functions.
4. `server/utils/array_utils.go`: delete `Insert`, `Contains`, `Map` (no callers); drop the now-unused `errors` import. Keep `Find` (google_calendar.go:142), `ArrayToSet` (postgres_group.go:743-744, user.go:332), `FindAddedRemovedKept` (postgres_group.go:213), and `ElementWithIndex`.
5. `server/respondents/identity.go`: rename `GuestNameObjectIDLike` to `GuestNameAccountIDLike` and its internal code value `"object_id_like"` to `"account_id_like"`, matching the frontend's existing `accountIdLike` term. Update call sites in `server/routes/respondent_identity.go:45`, `server/respondents/identity_test.go:29`, and `server/routes/guest_response_ownership_test.go:66`. The API-visible message already reads "Guest name cannot look like an account ID" and stays unchanged; the validation code string is not serialized (only `guestNameError.message` reaches the wire).
6. Verification: `go build ./...` and `go vet ./...` from `server/`, then the Compose-backed server test suite. Frontend checks are not required because no server wire contract changes.

## Scope Notes

- No behavior or wire shape changes: removals are unreferenced code; the guest-name validation message and all serialized payloads are unchanged.
- `ActualCalendarAccountMapKey` and other live compatibility paths are untouched.

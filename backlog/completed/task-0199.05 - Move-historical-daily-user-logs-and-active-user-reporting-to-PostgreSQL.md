## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented the runtime move and account-deletion cleanup. The resumable backfill of existing MongoDB `dailyuserlogs` is intentionally out of scope for this task per the confirmed scope decision and is tracked as TASK-0199.10, per the retained-data contract's backfill section.

Daily logs are keyed by a `log_date DATE` and memberships by `account_user_id` (the external user id in platform_identities), matching the existing `account_user_id` convention used by folders and responses. Profile fields are rebuilt from `accounts` at read time and never stored on the log.

The profile read records the membership; the Slack and Discord reporting paths share the repository's padded `ListActiveUserDays`, and `num_users` counts `accounts`.

Test helper `newAccountsTestRepository` now applies the daily-logs migration because `deleteAccountAuthority` touches the daily-log tables.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Outcome: server route code no longer qualifies domain concepts with postgres now that PostgreSQL is the only store, while genuine PostgreSQL technology naming stays.

Required scope:
- Rename server/routes/postgres_*.go files and their test files to names without the qualifier (for example postgres_event_routes.go -> event_routes.go, postgres_group.go -> group.go, postgres_identity.go -> identity.go, postgres_owner.go -> owner.go, postgres_grants.go -> grants.go, postgres_transfers.go -> transfers.go, and the corresponding postgres_*_test.go files).
- Drop the postgres/Postgres qualifier from route domain symbols and test names: repository accessors (postgresRepository), event/group/visitor/owner/grant/transfer/signup helpers and types, dashboard, folder, and account test seams such as DeletePostgres.
- Rename the wire-visible error string postgres-event-store-unavailable to event-store-unavailable.
- Absorb TASK-0216: rename server/routes/anonymous_event_compatibility_test.go and its helpers so they describe the single PostgreSQL event API contract and contain no multi-store abstraction.
- Keep without change: the server/postgres package and pgstore alias, POSTGRES_* variables, pgx/pgconn usage, the postgresError SQLSTATE wrapper, and server/postgres/** file names.
- Do not rename test cases that genuinely exercise PostgreSQL error behavior; only remove the redundant store qualifier.

Dependency: TASK-0233.01 renames the SQL objects this code queries, so take this task after the schema rename lands.

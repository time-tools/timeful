## Description

## Outcome

Build confidence that browsers without engine-native Temporal (notably Safari/WebKit as of Aug 2026) work correctly after the temporal-polyfill 1.x upgrade, by adding Playwright WebKit e2e smoke coverage that exercises Temporal-dependent flows on the JS-polyfill implementation path.

## Context

After TASK-0116, unit tests (Node 26) and Firefox e2e (Firefox 139+) run on engine-native Temporal via 1.x native delegation. The package's JS polyfill path is then only exercised by real WebKit browsers. Existing browser checks are Firefox-focused under `e2e/` with `e2e/playwright.config.ts`. This follow-up was explicitly deferred from TASK-0116.

## Constraints

- Smoke coverage only: a small number of representative Temporal-dependent flows, not full parity with the Firefox suite.
- Browser e2e always uses the isolated test stack owned by Playwright (postgres-test, server-test on 3003, then Vite on 4174); never the development API on 3002.
- Keep repo-tracked browser checks under `e2e/`.
- Test-only scope: do not change app import sites or the runtime dependency.
- Re-verify at execution whether Safari/WebKit has shipped native Temporal; if it has, re-scope or close this task instead of forcing coverage of an unreachable polyfill path.

## Outcome

Limit the self-hosted font weights and subsets to what the UI actually uses so the production build stops emitting unused woff and woff2 assets.

## Context

- `frontend/src/main.ts` imports `@fontsource/chivo-mono` 300/400/500 and `@fontsource/dm-sans` 400.
- The recorded build emits 23 font files (~270 KB) spanning latin, latin-ext, and vietnamese subsets in both woff and woff2 formats.
- Browsers only fetch subsets matched by `unicode-range`, so the user-facing transfer win is limited; the primary goal is emitted build weight and unused-asset cleanup.
- Chivo Mono must keep applying to mono elements per the TASK-0175 regression context.

## Constraints

- Keep the existing `@fontsource` approach; do not introduce new font tooling or self-hosted binaries.
- Record which subsets and weights remain and why each is needed.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The default Vite dev-server path used by browser E2E intermittently loads a blank event shell when module requests fail with `net::ERR_NETWORK_CHANGED`. The bundled frontend path passes the affected changed Chromium scope, but it is opt-in and does not establish default-mode reliability. This separate follow-up owns reproduction, diagnosis, and a supported default-mode resolution.
<!-- SECTION:DESCRIPTION:END -->

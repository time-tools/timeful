## Outcome

Remove the app shell's non-critical dialogs and their exclusive component dependencies from the initial eager bundle so first load no longer downloads dialog-only Vuetify components and form code.

## Context

- `frontend/src/App.vue` statically imports `SignInNotSupportedDialog`, `GrantedAccessConfirmation`, `SignInDialog`, `NewDialog`, and `UpvoteRedditSnackbar`; `NewDialog` statically pulls in `NewEvent`, `NewGroup`, `NewSignUp`, and `UnsavedChangesDialog`.
- The recorded eager preload set from the built `index.html` includes VDialog, VImg, VChip, VInput, VCheckbox, and VSpacer chunks, and the entry chunk is 237 KB raw / 75 KB gzip.
- Dialog components are still rendered conditionally; their visible behavior and `v-model` contracts must not change.
- `AutoSnackbar` is always active in the shell and is not a candidate for deferral.

## Constraints

- Keep the existing component contracts and unit tests intact; update tests only where the loading mechanism changes observable timing.
- Each deferred dialog must still open on first interaction, including when it is opened before its code has been fetched.
- An empty or broken first-open experience is a regression, not an acceptable tradeoff.

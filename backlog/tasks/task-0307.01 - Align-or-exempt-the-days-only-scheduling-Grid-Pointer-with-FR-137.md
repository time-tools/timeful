## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
FR-137 and the glossary Grid Pointer entry govern the scheduling Grid Pointer only on the Timed Grid of the Timed Event Scheduling Page.
A days-only event still renders its own Grid Pointer (`schedule-overlap-days-only-grid__selected-timeslot`) from click, tap, and hover during scheduling, because the days-only renderer gate and the shared `getTimeslotVon` handlers were deliberately left unchanged by TASK-0307.
On a phone viewport with responses, tapping a day during days-only scheduling therefore still shows the pointer, which is the behavior FR-137 removed from the Timed Grid.

TASK-0307 qualified the glossary to the Timed Grid and kept the days-only behavior unchanged, but the product decision for the days-only scheduling grid is still open: either the same scheduling rule applies to it, or the exclusion is explicit.
This task covers making that decision and then aligning the requirement documents and the days-only behavior with it.
The existing days-only Availability Editing behavior must stay unchanged.
<!-- SECTION:DESCRIPTION:END -->

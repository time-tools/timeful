## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## Outcome

Make the rewrite procedure reachable the way an agent is actually invoked in this repository, without duplicating any of it.

`.agents/skills/` is already the registered skill path and needs no agent configuration change, so a skill here is a pure routing concern.
Its value is that an agent asked to "rewrite this file in GALA" finds the preconditions, the stop conditions, and the exact commands immediately, instead of discovering that the roster exists and then reconstructing an order of operations from an eleven-column table.
Without it the procedure is only reachable if the agent already knows to go looking for it.

This task depends on TASK-0330.03 for the playbook it routes to and on TASK-0330.02 for the catalog the playbook points at.

## Requirements

- The skill loads from the existing registered path and needs no agent configuration change.
- Its frontmatter matches the shape used by the skills already in the repository.
- Its body gives the preconditions, the ordered steps with their stop conditions, the exact commands, and pointers to the playbook, the roster, the spike record, and the probe corpus.
- It states the conditions under which the rewrite must not be attempted, so an agent asked to translate an untranslatable file stops and says so rather than reshaping a Go-facing API.
- It keeps no construct verdict, probe name, or occurrence count of its own; anything it states is traceable to the page it points at.

## Constraints

- The skill is documentation and agent instruction only: no runtime code, no build or deployment configuration, no generated artifact.
- Frontmatter uses only the two keys the existing skills use, and the description follows their trigger-clause shape so the skill is discovered the same way as the others.
- It matches the sentence-per-line rule in `docs/AGENTS.md` by hand, because the repository's Markdown tooling excludes this path from both the formatter and the linter.
- It must not restate the playbook's procedure in a form that can diverge from it.
  Where a step needs a decision, it names the page that holds the decision.
- The path of the playbook page is whatever TASK-0330.03 created; confirm it rather than assuming a name.

## Evidence required

- The skill loading through the agent's skill loader, recorded in the task notes.
- A read-through confirming every cited path and command exists, recorded in the task notes.

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Phase 2 of TASK-0224. Use the TASK-0224.01 audit results to finish the FR-119 event-name constraint lifecycle and resolve any violation the live databases still report.

TASK-0224.01 closed with no live legacy rows: the development database is baseline-created and empty, and TASK-0224.04 recreates staging and production from the baseline. This phase therefore reduces to the constraint lifecycle on the recreated databases and updating the repository assertion, with cleanup needed only for any violation the recreated databases accumulate after the recreate.

Outcome: every violation class from the audit is resolved or explicitly accepted, and every database reaches a recorded final state: either the constraint is validated after cleanup, or the database is recreated from the baseline under the documented policy.

## Context

TASK-0353 decides that server GALA twins adopt the published module `go.gala.fyi/stdlib` v0.87.1, and its scope is every existing twin plus the remaining translation cursor. TASK-0353.01 lands the go.mod/verify.sh contract; TASK-0353.02 updates the translation skills. This task performs the migration and continues moving server code to GALA.

Current state: 22 committed twins across 15 packages, all runtime-free, with the cursor at `models/set.go`, `models/location.go`, `models/event.go` (blocked on struct tags and `struct{}`, which stay blocked whatever the runtime), then `routes/group.go`, `postgres/`, `main.go`, the observability trio, the services group, and `mockprovider`/`services/gcloud/tasks.go` (see `server/GALA.md`). TASK-0349 continues to own the runtime-free loop and is deliberately left as-is.

## Outcome and constraints

Move each twin to the runtime-native spelling where the emitted Go keeps the package's Go-facing surface identical, and translate the remaining cursor candidates where the runtime or the current compiler allows. Where a runtime construct changes the surface (an exported `val` becoming `std.Immutable`, a sealed type's merged struct, non-`var` struct fields gaining wrappers, `Codec` changing a wire shape), keep the current runtime-free form or a handwritten sibling and record why in `server/GALA.md`.

## Process

- Follow the `gala-loop` skill one iteration at a time; re-check each construct on the pinned compiler (`cd2fdcb5`, per `server/GALA_COMPILER`) before writing GALA.
- Transpile from the package directory with `--stdlib-module go.gala.fyi/stdlib`; per twin confirm a double transpile is byte-identical and `gofmt`-clean, then run `verify.sh`, `go build ./...`, and the canonical Compose test sequence.
- Update the registry row (runtime status and regeneration command), the cursor, and the open findings after each iteration; add or remove probes as findings change.
- Existing runtime-free twins that already meet the contract need no rewrite without a recorded reason; prefer the smallest change that exercises the adopted runtime.
- Record per-iteration provenance and evidence in the task notes; format changed Markdown with `npm run format:markdown`.
